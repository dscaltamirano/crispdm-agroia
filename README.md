# CRISP-DM | AgroIA

Tutorial de ciencia de datos aplicado al análisis de la
producción de piña en México mediante la metodología CRISP-DM.

## Objetivo

Analizar datos históricos de producción agrícola (2003–2025)
para identificar patrones, estudiar tendencias y desarrollar
modelos de aprendizaje automático que apoyen la toma de decisiones.
